# Country Search — design notes

## 1. Отмена устаревших запросов

- Каждый запрос получает свой `AbortController`. Контроллер текущего запроса хранится
  в замыкании `createSearchController` (`src/core/searchController.ts`).
- Отмена происходит **на каждый ввод** (метод `input`), а не только когда debounce
  отправляет новый запрос. Иначе ответ на старый запрос может прийти во время ожидания
  debounce и показаться под новым текстом.
- В `searchCountries` (`src/core/searchCountries.ts`) свой сигнал объединяется с таймаутом:
  `AbortSignal.any([signal, AbortSignal.timeout(TIMEOUT_MS)])`. По `name` ошибки
  `classifyError` отличает свою отмену (`AbortError`, не показывается) от таймаута
  (`TimeoutError`, показывается с кнопкой «Повторить»).
- Почему не флаг «ответ устарел»: флаг только прячет старый ответ, а сам запрос
  продолжает грузиться (сеть, сервер, в Network он не `canceled`). Отмена прерывает его
  по-настоящему.
- Тесты гонки (`src/core/searchController.test.ts`): ответы в обратном порядке, ответ во
  время ожидания debounce, и проверка, что сигнал первого запроса отменён.

## 2. Задержка debounce: 600 мс

- Замер своего набора: без задержки — запрос на каждую букву (15 на одно слово),
  при 300 мс — 4 запроса, при 1000 мс — 1.
- Без debounce: лишние запросы на каждую букву, большинство тут же отменяются.
- При сильном увеличении: после последней буквы пользователь долго смотрит на пустой
  экран и решает, что поиск не работает.
- 600 мс — компромисс: при таком промежутке не вызывается запрос на каждую букву, при это не слишком долго

## 3. Сложность

- `mapCountryResponse(raw)` — одна страна: копирует поля и проходит по `languages` (L)
  и `currencies` (C) через `map`. Время O(L + C), память O(L + C).
- Для списка из n стран отрисовка вызывает маппинг n раз: O(n · (L + C)). L и C малы
  (обычно 1–3), поэтому на практике это O(n).
- Кэша (бонус) нет.

## 4. Принципы чистого кода

- **Одна ответственность:** `searchCountries` — только сеть и статусы; `classifyError` —
  только различение ошибок; `mapCountryResponse` — только форма данных; `render`
  (`src/ui/main.ts`) — только DOM.
- **Чистые функции:** `mapCountryResponse` и `classifyError` не меняют вход и не
  трогают сеть и DOM (есть тест на неизменность входа).
- **Данные отдельно от текста:** при отсутствии данных маппинг возвращает `null`, а что
  показать человеку, решает отрисовка.
- **Явные типы вместо строк:** `HttpError` со статусом, размеченные объединения
  `SearchState` и `SearchError`; `switch` по `kind` в `render` перебирает все состояния.
- **Именованные константы:** `BASE_URL`, `TIMEOUT_MS`, `DELAY_MS`.
